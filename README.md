# animate_this

A reference toolkit for picking the right animation for any UI interaction.

## Project Structure

```
animate_this/
├── Mobile/      # React Native (Expo) — iOS & Android
├── Web/         # Web version — built with GitHub Spark (coming soon)
└── reference/   # HTML design source (Stitch exports)
```

## What this app does

Developers and designers pick **what they're trying to do** (screen transition, show/hide UI, feedback, loading, drag, forms) and the app guides them to a documented animation pattern with copy-pasteable specs (easing, duration, spring config, choreography).

## Mobile

```bash
cd Mobile
npm install
npx expo start
```

## Web

Built using GitHub Spark. See `Web/` for the source.
